# 隐私政策

生效日期：2026-08-16

本隐私政策说明 CDict（以下简称「本应用」）如何收集、使用与保护信息。核心原则：**数据完全本地，不收集、不上传任何个人信息**。

## 1. 我们收集什么

**本应用不主动收集任何个人信息。**

- 词典数据、背词进度、推荐进度、翻译缓存等全部存储在设备本地。
- 应用仅声明 `INTERNET` 权限，用于可选的在线翻译与发音。

## 2. 我们如何使用信息

### 本地数据

以下数据仅保存在你的设备上，不会上传：

- 背词与复习进度、每日目标
- 搜索与翻译缓存（含 Room 持久化缓存与内存缓存）
- 发音音频磁盘缓存（50 MB LRU）

### 在线请求

以下在线功能仅在**你主动操作时**发起请求，请求内容为对应的文本或发音文本，不附带你的个人信息。除赞赏收款码图片一项（见下）外，所有请求只发往本项目自有后端 `https://tts.chloemlla.com`，由该后端转发到上游服务：

- **在线翻译**：向自有后端发送你要翻译的文本，由后端转发给上游翻译网关。
- **在线发音**：向自有后端发送要朗读的单词或短语，由后端转发给上游语音合成或词典音频接口。
- **词典更新检测**：仅读取本地词库签名进行比对，不对外发送任何词典内容。
- **赞赏码获取**：打开「赞赏支持」页面时，向自有后端拉取说明文案、渠道列表与鸣谢名单。收款码图片的请求会被后端 `302` 跳转到运营方在后台配置的图床地址，图片由该图床直接返回，因此这一跳会连接到该图床（它能看到你的 IP 与 UA，与你在浏览器里打开一张图片无异）；后端不下载也不缓存图片字节。安装包内不内置任何收款码或收款账号；上述请求只包含渠道标识，不附带你的任何信息，也不上报是否赞赏。累计前台使用时长仅保存在设备本地设置中，用于判断一次性提示是否出现，不联网上报。
- **署名申请（可选，需你主动填写并点击提交）**：鸣谢名单中的名字来自赞赏者自己在转账备注中填写的称呼，或你在赞赏支持页「申请加入鸣谢名单」表单中主动提交的内容。提交时只向自有后端上传你填写的**交易号**与**希望展示的称呼**两项，不附带 IP 之外的任何设备信息，也不采集账号、手机号或支付账户信息；后端只保存这两项，开发者核实后即从待核实列表中删除，加入名单的只有你指定的称呼（会公开展示）。不提交表单、不写备注就是匿名支持，应用不会自动收集或上传任何署名信息。为防误触，应用本地会记录上次提交时刻与一小时内的提交次数（仅存于设备本地设置，不上报）。

### 崩溃上报

应用集成了 Lumen Crash SDK，用于在应用崩溃时采集崩溃信息（崩溃堆栈、设备型号、系统版本等）。采集在本地进行与展示；是否进一步上报以 SDK 与对应仓库的行为为准。

## 3. 第三方服务

在线翻译与发音由本项目自有后端代理到第三方接口。自有后端不保存请求文本；上游接口按各自的服务条款处理转发过去的请求数据，我们无法控制第三方对数据的处理方式。若你不希望发起这些请求，可以完全离线使用词典核心功能，或拒绝相应权限。

## 4. 数据安全

除你主动提交的署名申请（交易号与称呼两项，核实后删除，见上）外，所有数据仅保存在设备本地应用沙盒内；我们不会在服务器存储你的其他任何数据。

## 5. 儿童隐私

本应用不面向 13 岁以下儿童，也不会有意收集儿童的个人信息。

## 6. 政策变更

我们可能适时更新本政策。更新后将在本页面发布；重大变更会通过应用内更新说明提示。
